# CT029-3-2-Imaging and Special Effects - Group Assignment

## COURSEWORK OBJECTIVES

- Develop and implement special effects in digital media using appropriate workflows
  and techniques.

- Create  a  compelling  digital  artefact  utilizing  digital  image  processing  and  computer
  graphic techniques.

## COURSEWORK TITLE

Develop an Interactive Game Artifact with Special Effects

## COURSEWORK TYPE

Group Project

## COURSEWORK OVERVIEW

This coursework contributes to 60% of the overall module weightage.  Students will work in a
group  to  develop  an  interactive  game  with  flora  theme.  The  assignment  will  require  the
integration of various imaging and special effects techniques, utilizing appropriate modelling
tools, game engines, and Application Programming Interfaces (APIs). Students are expected to
implement both visual and audio special effects, including but not limited to sprite animations,
particle effects, and motion tracking. Additionally, the game should incorporate event-driven
gameplay to enhance interactivity and user engagement.

## COURSEWORK DESCRIPTION

The assignment involves a series of tasks from writing a narrative, designing and modelling
assets  (models,  environment,  sprites)  and  finally  integrating  it  into  a  functional  game.   The
game should include at least two levels, each with unique challenges and environments based
on the narrative storyboard.

The game should showcase the use of visual programming tools and libraries such as Pygame
(2D game engine) or Ursina Engine (3D game engine). Additionally, you may any modelling
or animation tools to create models / sprites / characters and environments for the game, and
incorporate  visual  or  audio  special  effects  to  drive  the  event  sequences  (e.g.,  spore  burst,
healing aura, glowing cap) to enhance the user experience.

## Detailed Requirements

### Group Formation

- Each group will consist of four students with each student responsible for 1 scene.

### Theme

- The game should be based on a flora theme.

- Suggested artefact name: "Flowerpower" (or any name of your choice).

### Narrative

Write a narrative storyboard for the game artefact.  The narrative should revolve around flora
and include character design, movement, and event-driven actions. The storyboard should
outline the following information.

- The main characters and their abilities.

- The environment settings such as arena and background.

- Plot and mechanics (ex. Comet collision and floor fracture)

### Game Assets

Create the following game assets and integrate it in the final game development.

- Visual  assets  should  encompass  backgrounds,  sprites,  textures,  animation,  particle
  effects.

- Audio Assets  should  encompass background  music and  sound effects  such  as  noise,
  character voice or  audio clips.

- Any other necessary assets to define the event-driven actions / obstacles / terrains and
  game logic.

### Artefact Implementation

- Setup the game environment using Pygame or Ursina Engine.

- Implement the game concepts, logic and mechanics based on the narrative.

- Integrate the visual and audio assets in the previous sections into the game environment.

- Apply special effects to enhance attacks or major events in the game.

### Artefact Demo

- A  recorded  demo  to  demonstrate  that  your  game  is  fully  functional,  with    proper
  gameplay flow. No explanation or narration is required (optional).

### Assignment Test

- To assess your knowledge and understanding, and also technical skills relevant to the
  imaging and special effects coursework.

### Verification of Student Understanding

In recognition of the increasing use of AI-generated content, students must demonstrate their
own understanding of the work they submit. A test will be administered after the assignment
submission. The score obtained in this test will serve as a multiplier on the development marks
earned from the artefact.

For example:

- Artefact score: 35/20

- Test score: 8/10 → multiplier = 0.8

- Adjusted development marks = 0.8 × 35 = 28/40

This  ensures  that  marks  awarded  reflect  both  the  quality  of  the  artefact  and  the  student’s
personal comprehension, thereby discouraging over-reliance on AI tools.
